# APMollerMaersk_OlistECommerceAgent
GenAI-powered agentic system that provides conversational analytics for the Olist E-commerce dataset on Streamlit Interface . The features include a Text-to-Pandas Chat Agent (OpenAI/OpenRouter), Analytics Dashboards, Sales forecasting (Holts Winters Model), Customer Clustering (KMeans), and Semantic RAG search (FAISS).
